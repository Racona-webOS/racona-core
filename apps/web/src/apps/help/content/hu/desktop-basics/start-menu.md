Az Indító panel az összes telepített alkalmazás központi elérési pontja.

## Indító panel megnyitása

- Kattints az Indító panel gombra a tálca bal oldalán

## Rács nézet

A rács nézet az alkalmazásokat ikonokkal jeleníti meg:

- Az alkalmazások rács elrendezésben jelennek meg
- Minden alkalmazásnak van ikonja és neve
- Görgess le/fel a további alkalmazások megtekintéséhez
- Kattints egy ikonra az alkalmazás indításához

![Placeholder: Indító panel rács nézetben megnyitott alkalmazásokkal](../../../../../assets/desktop/startmenu-icon.webp)
_Indító panel rács nézetben_

## Lista nézet

A lista nézet az alkalmazásokat lista formátumban jeleníti meg:

- Az alkalmazások függőleges listában jelennek meg
- Kompaktabb megjelenítés több alkalmazás számára
- Váltás a rács és lista nézet között a nézet váltó gombbal
- Kattints egy elemre az alkalmazás indításához

![Placeholder: Indító panel lista nézetben](../../../../../assets/desktop/startmenu-list.webp)
_Indító panel lista nézetben_

## Keresési funkció

A keresés gyorsan megtalálja a kívánt alkalmazást:

1. Nyisd meg az Indító Panelt
2. Kezdj el gépelni a keresőmezőbe
3. Az alkalmazások lista automatikusan szűrődik
4. Kattints a kívánt alkalmazásra vagy nyomj Enter billentyűt

## Alkalmazások indítása

Alkalmazás indítása az Indító Panelből:

1. Nyisd meg az Indító Panelt
2. Keresd meg vagy keress rá az alkalmazásra
3. Kattints az alkalmazás ikonjára vagy nevére
4. Az alkalmazás elindul és megjelenik egy új ablakban

## Asztali parancsikon létrehozása

Asztali parancsikon létrehozása az Indító Panelből:

1. Nyisd meg az Indító Panelt
2. Keresd meg a kívánt alkalmazást
3. Húzd az alkalmazás ikonját az asztalra
4. A parancsikon automatikusan létrejön az asztalon

További információ: [Asztali parancsikonok](/hu/user/desktop-basics/desktop-icons/)

## Indító panel testreszabása

Az Indító Panel megjelenését testreszabhatja a Beállítások alkalmazásban:

- **Nézet**: Rács vagy lista
- **Keresési beállítások**: Keresés viselkedése

[Indító panel beállítások →](/hu/user/applications/settings/)
