## What is Racona?

Racona is a modern, web-based platform that combines the functionality of traditional desktop operating systems with the flexibility of modern web technologies — all directly in your browser. The system allows you to:

- **Access from anywhere**: All you need is a browser
- **Provide authenticated access**: Secure session after login
- **Offer customizable interface**: Personalize appearance and behavior
- **Be extensible**: Install plugins and applications

## Key Features

### Desktop Environment

Racona provides a full-featured desktop environment:

- **Window Management**: Use multiple applications simultaneously
- **Taskbar**: Quick access to applications and system functions
- **Start Menu**: Central place to launch applications
- **Desktop Shortcuts**: Frequently used applications on the desktop

### Core Modules

Racona is a modular webOS framework that comes with essential modules for operation:

- **Settings**: Configure the system
- **Chat**: In-system messaging between users
- **Log**: View system events and log entries
- **Notifications**: Manage system notifications
- **Users**: Manage user accounts (admin function)

The system can be extended with additional applications and plugins according to specific needs.

### Customization

Personalize Racona:

- **Themes**: Light, dark, or automatic mode
- **Colors**: Choose custom color schemes
- **Backgrounds**: Color, image, or video backgrounds
- **Taskbar**: Customize position, style, and elements
- **Language**: Hungarian and English language support

### Security

Racona takes security seriously:

- **Authentication**: Multiple login methods
- **Two-Factor Authentication (2FA)**: Extra protection for your account
- **Session Management**: Secure session preservation
