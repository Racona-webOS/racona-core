# Frequently Asked Questions (FAQ)

## General Questions

### What is Racona?

Racona is a modern, web-based operating system that runs in your browser.

### Is Racona free?

Yes, Racona is open source and free to use.

### Which browsers does it work in?

Racona works in all modern browsers: Chrome, Firefox, Safari, Edge.

## Technical Questions

### Where are my files stored?

Files are stored securely on the server.

### Can it be used offline?

Racona requires an internet connection to function. Depending on the installation location (cloud-based service or own server), network requirements may vary, but network connection is always necessary for basic operation.

### How secure is it?

Racona uses modern security technologies to protect your data.

## Developer Questions

### Can I develop my own application?

Yes! Check out the [developer documentation](https://docs-dev.racona.hu/en/getting-started/).

### What technologies does Racona use?

Racona is built on modern web technologies: TypeScript, Svelte, Node.js.
