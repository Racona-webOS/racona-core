The Settings application is the central configuration hub of Racona. Here you can customize the system's appearance, behavior, and features.

## Basic Information

- **Category**: System
- **Multi-instance**: No
- **Permission**: Public (all users)

## Account

In the Account menu item, you can manage your personal profile data.

### Profile Picture

- **Upload profile picture**: Upload your own profile picture (max. 5 MB, JPG, PNG, WebP format)
- **OAuth synchronization**: If you logged in with an OAuth provider (e.g., Google), the profile picture automatically synchronizes
- **Default avatar**: If there is no profile picture, the system generates an initial avatar from your name

### Personal Data

- **Name**: Edit full name (required field)
- **Username**: Set unique username (optional)
- **Email address**: Display email address (not editable)
- **Account type**: Shows whether you have an email/password or OAuth account

### Groups and Roles

- **Groups**: Display groups assigned to the user
- **Roles**: Display roles assigned to the user
- **Creation date**: The time when the account was created

**Tip**: Click the Edit button to modify your data, then finalize the changes with the Save button.

## Security

In the Security menu item, you can manage your account's security settings.

### Two-Factor Authentication (2FA)

Two-factor authentication adds an extra security layer to your account.

**Enabling 2FA:**

1. Enter your current password
2. Click the "Enable 2FA" button
3. Scan the QR code with an authenticator app (e.g., Google Authenticator, Authy)
4. Enter the 6-digit code generated by the authenticator app
5. Save the backup codes in a secure place

**Backup Codes:**

- 10 single-use codes
- Use them if you don't have access to the authenticator app
- Copy or download them to a secure place
- You can generate new codes at any time

**Disabling 2FA:**

1. Enter your current password
2. Click the "Disable 2FA" button

### Change Password

Change your account password for security.

1. **Current password**: Enter your current password
2. **New password**: Enter the new password (minimum 8 characters)
3. **Confirm password**: Re-enter the new password
4. Click the "Change Password" button

**Password requirements:**

- Minimum 8 characters long
- Must contain at least one uppercase letter (A-Z)
- Must contain at least one lowercase letter (a-z)
- Must contain at least one number (0-9)
- Cannot be the same as the current password

## Appearance

In the Appearance menu item, you can customize the visual appearance of Racona.

### Theme Presets

Choose from pre-configured theme presets that set the color scheme, theme, and background all at once.

- **Preview**: Each preset displays the theme mode, color scheme, and background
- **Quick apply**: Apply the complete theme with one click

### Desktop Theme

Choose between desktop theme modes:

- **Light**: Displays the entire system with a light color scheme (desktop, applications, UI elements)
- **Dark**: Displays the entire system with a dark color scheme (desktop, applications, UI elements)
- **Auto**: The system automatically switches between light and dark themes based on time of day

### Taskbar Theme

Choose between taskbar theme modes (independent of desktop theme):

- **Light**: Displays the taskbar with a light color scheme
- **Dark**: Displays the taskbar with a dark color scheme
- **Auto**: The system automatically switches between light and dark themes based on time of day

**Tip**: The taskbar theme can be set independently of the desktop theme. For example, you can use a dark taskbar on a light system, or vice versa, creating unique visual contrast.

### Color Scheme

The primary color determines the application's accent color, which appears in buttons, links, and other interactive elements. Choose a predefined color or create a custom color with the hue slider.

### Font Size

Adjust the interface font size to improve readability.

**Tip**: Font size setting affects the size of text throughout the entire system. Larger font size provides easier readability, while smaller font size displays more information on the screen.

## Desktop

In the Desktop menu item, you can set the behavior of the desktop environment.

### Opening Mode

Choose between desktop shortcut opening modes:

- **Single click**: Opens applications with one click
- **Double click**: Opens applications with double click (traditional mode)

## Background

In the Background menu item, you can customize the desktop background.

### Background Type

Choose from three background types:

- **Color**: Solid color background
- **Image**: Use background image
- **Video**: Use video background

### Color Background

If you choose the Color type:

- **Color picker**: Choose any color with the color picker
- **Instant apply**: The selected color is applied immediately

### Image Background

If you choose the Image type:

**System Images:**

- You can choose from pre-installed background images
- Thumbnail previews help with selection

**Upload Your Own Image:**

- Upload your own background image
- Supported formats: JPG, JPEG, PNG, WebP
- Maximum file size: 10 MB
- Automatic thumbnail generation

**Managing Uploaded Images:**

- View all uploaded images
- Delete unused images
- The delete button appears when hovering over the image

**Image Effects:**

- **Blur**: Apply blur between 0-30 pixels (adjustable with slider)
- **Grayscale**: Convert the background image to black and white

### Video Background

If you choose the Video type:

- **System Videos**: You can choose from pre-installed videos
- **Thumbnail previews**: Each video has a preview image
- **Supported formats**: MP4, WebM, OGG

**Note**: Video background can be resource-intensive, on slower devices it's worth using an image or color.

## Taskbar

In the Taskbar menu item, you can set the appearance and behavior of the taskbar.

### Position

Select the position of the taskbar on the screen:

- **Top**: The taskbar appears at the top of the screen
- **Bottom**: The taskbar appears at the bottom of the screen (default)

### Style

Choose between taskbar styles:

- **Classic**: Full-width taskbar
- **Modern**: Floating, centered taskbar

### Taskbar Element Visibility

Set which elements appear on the taskbar:

- **Clock**: Display date and time
- **Theme switcher**: Quick switch between light/dark themes
- **Application Link**: Open GUID links
- **Messages**: Quick access to Messages application
- **Notifications**: Open notification center

There is a toggle next to each element to turn the element on/off.

## Start Panel

In the Start Panel menu item, you can set the appearance of the application launcher.

### View Mode

Choose between two view modes:

- **Grid view**: Applications appear with icons in grid layout
- **List view**: Applications appear in list format with detailed information

## Performance

In the Performance menu item, you can optimize system performance.

### Performance Optimization

- **Prefer performance**: Disables resource-intensive visual effects
- When enabled, only the frame is visible while moving windows, the content does not appear
- Automatically disables window previews and other visual features
- Significantly reduces browser resource usage, especially on slower devices

### Window Previews

- **Enable preview images**: Inactive windows have preview images on the taskbar
- **Disable**: Faster operation, but no preview
- Only available when performance optimization is disabled

**Warning**: Preview images are resource-intensive and can slow down application minimization time.

### Preview Image Size

If window previews are enabled, you can set the size of preview images:

- **Small** (100px): Smallest size, fastest
- **Medium** (150px): Balanced size (default)
- **Large** (200px): Largest size, best quality

Visual icons on the slider indicate the sizes.

## Language

In the Language menu item, you can set the interface language.

### Interface Language

- **Language selection**: Choose from supported languages
- **Instant apply**: The selected language is applied immediately

**Currently supported languages:**

- Magyar (Hungarian)
- English (coming soon)

**Note**: This menu item only appears if multiple languages are available in the system.

## AI Assistant

In the AI Assistant menu item, you can customize the AI Assistant's appearance and voice output. Additional settings are available for administrators to configure the AI system.

### Avatar Settings

Avatar settings allow customization of the AI Assistant's visual appearance.

**Select avatar:**

- Choose from installed avatars
- Preview: Real-time preview of the selected avatar
- Quality: SD (Standard Definition) or HD (High Definition)

**Note**: Installing new avatars requires administrator privileges (see below: Avatar Installation).

### TTS (Text-to-Speech) Settings

TTS settings allow customization of voice output.

**Voice settings:**

- **Select voice**: Choose from available voices
- **Speed**: Set speech speed (0.5x - 2.0x)
- **Volume**: Set volume level (0% - 100%)
- **Test**: Try out the settings with a test sentence

**Tip**: To test TTS settings, click the "Test" button (play icon) at the bottom of the window.

**Note**: Configuring the TTS provider requires administrator privileges (see below: TTS Provider Configuration).

### AI Agent Configuration (admin only)

The AI Agent is the system's central AI engine that enables the AI Assistant to function. This menu item is only available to users with administrator privileges.

**Enable AI Agent:**

- **On**: The AI Agent is active, the AI Assistant is usable
- **Off**: The AI Agent is inactive, the AI Assistant is unavailable

**Configuration:**

- **Provider**: Choose AI provider (Google Gemini, OpenAI, Anthropic, Groq, Hugging Face or a custom endpoint)
- **API Key**: Enter the provider's API key
- **Model**: Pick the model from the provider's list. When you switch providers, the provider's default model is selected. If the model is not in the list, choose "Custom model…" and enter its ID. For a custom endpoint, enter the model ID by hand.
- **Base URL**: Optional custom API endpoint URL

**Available models:**

At the bottom of the panel you can manage the models of the selected provider:

- **Switch**: when off, the model does not appear in the model picker
- **Star**: makes the model the provider's default
- **New model**: enter the model ID (e.g. gpt-6.1-sol) and optionally a display name, then click Add
- **Delete**: only models you added yourself can be deleted; built-in models can only be turned off

**Advanced parameters:**

- **Max Tokens**: Maximum token count for responses (100 - 100,000)
- **Temperature**: Creativity level (0.0 - 2.0)
  - Low value (0.0-0.5): Consistent, predictable responses
  - Medium value (0.5-1.0): Balanced responses
  - High value (1.0-2.0): Creative, varied responses
- **Top P**: Response diversity (0.0 - 1.0)

**Testing:**

- Click the "Test Connection" button to verify the API configuration
- A green indicator appears on successful test

### TTS Provider Configuration (admin only)

TTS (Text-to-Speech) Provider configuration allows setting up the voice output service provider. This menu item is only available to users with administrator privileges.

**Enable TTS Provider:**

- **On**: The TTS service is active, the AI also reads responses aloud
- **Off**: The TTS service is inactive, text-only responses

**Provider types:**

- **Browser Web Speech API**: Built-in browser TTS (free, limited voices)
- **ElevenLabs**: Professional TTS service (API key required)

**ElevenLabs configuration:**

- **API Key**: Enter your ElevenLabs API key
- **Load voices**: Click the "Load Voices" button to list available voices
- **Select voice**: Choose from loaded voices
- **Language**: Select the desired language

**Testing:**

- Click the "Test Voice" button to try out the selected voice
- The test voice plays automatically

### Avatar Installation (admin only)

The Avatar Installation menu item allows uploading and installing new avatars into the system. This menu item is only available to users with administrator privileges.

**Upload avatar:**

1. Click the "Choose File" button
2. Select the `.raconapkg` format avatar package
3. Click the "Install" button
4. Wait for installation to complete

**Installed avatars:**

- View all installed avatars
- Each avatar card shows:
  - Avatar name
  - Preview image
  - Available qualities (SD/HD)
  - Installation date
- Click a card to view details
- Delete unused avatars (coming soon)

**Note**: The avatar package must be in `.raconapkg` format. Maximum file size: 50 MB.

## Authentication

The Authentication menu item is only available to users with administrator privileges. Here you can configure the system's authentication settings.

### Registration and Social Login

**Enable registration:**

- **On**: New users can register in the system
- **Off**: Only invited users can log in

**Enable social login:**

- **On**: Users can log in with Google account
- **Off**: Only email/password login is available

## System Information

In the System Information menu item, you can view Racona version information and contact details.

## Tips and Tricks

- **Instant save**: Most settings take effect immediately, no separate save needed
- **Application sharing**: The Settings application can be shared with GUID link - so you can quickly navigate others to a specific setting
- **Quick navigation**: Use the left menu to quickly switch between different settings categories

## Frequently Asked Questions

**Why don't I see the Language menu item?**
The Language menu item only appears if multiple languages are available in the system.

**How can I restore default settings?**
Currently there is no "Reset" button, but you can manually restore each setting to its default value.

**Why is the system slow with window previews?**
Window previews are resource-intensive. Turn them off in the Performance menu item for faster operation.

**Can I delete uploaded background images?**
Yes, you can delete your own uploaded images in Background > Uploaded Images - the delete button appears when hovering over the image. Built-in system images cannot be deleted.

**Why don't I see the Authentication menu item?**
The Authentication menu item is only available to users with administrator privileges. This menu item contains system-level settings such as registration and social login configuration.

**Why don't I see the AI Agent Configuration menu item?**
The AI Agent Configuration, TTS Provider Configuration, and Avatar Installation menu items are located under the AI Assistant main menu item, but are only visible to users with administrator privileges.

**How can I enable the AI Assistant?**
Enabling the AI Assistant requires administrator privileges. Administrators can enable and configure the AI Agent at Settings > AI Assistant > AI Agent Configuration.

**Where can I set the AI Assistant's avatar?**
Users can choose from installed avatars at Settings > AI Assistant > Avatar Settings. Installing new avatars requires administrator privileges (Settings > AI Assistant > Avatar Installation).

**Where can I configure TTS (voice output) settings?**
Users can set voice speed and volume at Settings > AI Assistant > TTS Settings. Configuring the TTS provider (Browser Web Speech API or ElevenLabs) requires administrator privileges (Settings > AI Assistant > TTS Provider Configuration).
