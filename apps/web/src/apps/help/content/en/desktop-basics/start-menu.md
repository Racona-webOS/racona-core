The Start Menu is the central access point for all installed applications.

## Opening the Start Menu

- Click the Start Menu button on the left side of the taskbar

## Grid View

Grid view displays applications with icons:

- Applications appear in a grid layout
- Each application has an icon and name
- Scroll down/up to view more applications
- Click an icon to launch the application

![Placeholder: Start Menu opened in grid view with applications](../../../../../assets/desktop/startmenu-icon-en.webp)
_Start Menu in grid view_

## List View

List view displays applications in list format:

- Applications appear in a vertical list
- More compact display for more applications
- Switch between grid and list view with the view toggle button
- Click an item to launch the application

![Placeholder: Start Menu in list view](../../../../../assets/desktop/startmenu-list-en.webp)
_Start Menu in list view_

## Search Function

Search quickly finds the desired application:

1. Open the Start Menu
2. Start typing in the search field
3. The application list automatically filters
4. Click the desired application or press Enter

## Launching Applications

Launching an application from the Start Menu:

1. Open the Start Menu
2. Find or search for the application
3. Click the application icon or name
4. The application starts and appears in a new window

## Creating Desktop Shortcuts

Creating a desktop shortcut from the Start Menu:

1. Open the Start Menu
2. Find the desired application
3. Drag the application icon to the desktop
4. The shortcut is automatically created on the desktop

More information: [Desktop Shortcuts](./desktop-icons/)

## Customizing the Start Menu

You can customize the Start Menu appearance in the Settings application:

- **View**: Grid or list
- **Search settings**: Search behavior

[Start Menu settings →](../applications/settings/)
