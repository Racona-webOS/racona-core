The context menu (right-click menu) provides quick access to context-sensitive actions. In Racona, context menus are available in multiple places, each offering options appropriate to the context.

## Using the Context Menu

1. Right-click on the desired area or element
2. The context-appropriate menu appears
3. Select an option from the menu
4. Or click elsewhere to close the menu

_Context menu on the desktop with right-click_

## Desktop Context Menu

Right-clicking on an empty area of the desktop provides the following options:

- **Customize background**: Opens the Settings application at background settings
- **Arrange desktop icons**: Automatically arranges shortcuts in a grid
- **Hide/Show desktop icons**: Hides or shows all desktop shortcuts

## Desktop Shortcut Context Menu

Right-clicking on a desktop shortcut provides the following options:

- **Open**: Launches the application
- **Rename**: Renames the shortcut label
- **Delete**: Deletes the shortcut from the desktop (the application is not deleted)

## Taskbar Context Menu

Right-clicking on an empty area of the taskbar:

- **Customize taskbar**: Opens the Settings application at taskbar settings

## Start Menu Button Context Menu

Right-clicking on the Start Menu button:

- **Customize Start Menu**: Opens the Settings application at Start Menu settings
